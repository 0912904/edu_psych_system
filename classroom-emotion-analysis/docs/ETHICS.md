# 伦理与隐私边界

这个项目分析的是课堂里真实存在的人。以下是我给自己划的界线，也是使用本项目的前提。

## 1. 输出是统计参考，不是心理诊断

系统给出的"消极情绪时间占比""情绪波动度""建议关注"，都只是**画面统计量**：某段时间里模型对某张脸的表情判断的汇总。

- 它不能诊断抑郁、焦虑或任何心理状态；
- 它不能用于对学生的评价、排名、奖惩或分班；
- "建议关注"的正确读法是"这段视频里该学生的画面统计与其他人不同，值得老师用自己的方式留意一下"，之后的判断必须由人做，最好由具备资质的心理教师做。

模型本身也远不可靠：在公开测试集上总体准确率约 57%，且明显偏向"中性"；小脸、侧脸、遮挡下进一步退化（见 `experiments/RESULTS.md`）。把这样的输出当结论是危险的。

## 2. 匿名化与最小留存

- 对外只显示"学生#N"，编号来自跟踪顺序，不关联姓名、学号或任何身份信息，也不做跨视频的身份关联；
- 不留存人脸图像：分析过程中如需生成临时视频副本（OpenCV 读不了含中文的路径），用完立即删除；
- 数据库只存结构化的分析结果（时间、情绪值、统计量），不存画面；
- 人脸框坐标只在当次分析结果里用于播放时叠加显示。

## 3. 真实课堂使用的前提

- 需要**校方授权**与**学生（及未成年人监护人）知情同意**，并事先说明采集范围、用途、留存期限与撤回方式；
- 录制设备与存储范围应限定在教学场所内，视频不得外传、不得用于训练第三方模型；
- 结果只应向相关任课教师或心理教师开放，不应在班级内公示；
- 学生有权要求删除与自己相关的数据。

## 4. 本仓库不包含什么

为了不把风险外扩，公开仓库**刻意不包含**：

- 任何真人课堂视频或含人脸的截图（`uploads/` 只留空目录）；
- 任何分析结果数据库（`*.db` / `*.sqlite`）；
- 从真人视频抽出的中间缓存（如 `experiments/results/video_faces.json`）；
- ONNX 模型权重（用 `scripts/download_models.py` 从上游获取）。

想复现消融实验，请使用你自己获得授权的视频，或使用公开的、许可允许的教学录像数据集。

## 5. 已知偏差

公开表情数据集以正脸、裁剪好的表演式表情为主，与真实课堂差异很大；不同年龄、性别、肤色、佩戴眼镜/口罩的人群上，表情识别的表现并不均衡，本项目没有做公平性评测。请不要把系统输出当成对任何群体的客观测量。
